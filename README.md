# יומן עבודה יומי - גרסת אינטרנט

זהו ריפו נפרד ונקי המיועד **רק לאירוח** (GitHub Pages) - לא לפיתוח. הוא מכיל עותק של קובץ האפליקציה בלבד, בלי שום נתון אמיתי (פרויקטים/קבלנים/פועלים/גיבויים) ובלי היסטוריית פיתוח - אלה נשארים בתיקיית הפיתוח המקומית והפרטית של הפרויקט.

`index.html` הוא עותק (לא הקובץ המקורי) של `יומן_עבודה_יומי_1.0.html` - נכון לתאריך ההעלאה. שינויים עתידיים בקוד יעודכנו כאן בנפרד, כשהאפליקציה תעבור לגרסת ה-Drive/Google Sign-In המתוכננת.
