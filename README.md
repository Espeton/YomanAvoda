# יומן עבודה יומי - גרסת אינטרנט

זהו ריפו נפרד ונקי המיועד **רק לאירוח** (GitHub Pages) - לא לפיתוח. הוא מכיל עותק של קובץ האפליקציה בלבד, בלי שום נתון אמיתי (פרויקטים/קבלנים/פועלים/גיבויים) ובלי היסטוריית פיתוח - אלה נשארים בתיקיית הפיתוח המקומית והפרטית של הפרויקט.

`index.html` הוא עותק (לא הקובץ המקורי) של `יומן_עבודה_יומי_1.0.html` - נכון לתאריך ההעלאה. שינויים עתידיים בקוד יעודכנו כאן בנפרד, כשהאפליקציה תעבור לגרסת ה-Drive/Google Sign-In המתוכננת.

## הוספת משתמש חדש (יומן עבודה + מעקב ביצוע)

1. **רשימת משתמשים מורשים:** Google Cloud Console ← Google Auth Platform ← Audience ← Test users ← הוספת כתובת המייל.
2. **שיתוף קובצי הנתונים:** ב-Google Drive של המנהל, לשתף עם המשתמש (הרשאת "עורך") את הקבצים
   `יומן-עבודה-נתונים.json` (יומן עבודה) ו-`מעקב-ביצוע-נתונים.json` (מעקב ביצוע).
3. **חיבור המשתמש לקובץ (פעם אחת, בכל אפליקציה):** המשתמש נכנס, ובמסך "לא נמצא קובץ הנתונים המשותף" לוחץ
   "בחר את קובץ הנתונים המשותף" ובוחר את הקובץ. הבחירה נשמרת בדפדפן. (בלי זה האפליקציה לא רואה קבצים ששותפו -
   זו מגבלה של ההרשאה `drive.file`.) רק המנהל (`ADMIN_EMAILS`) יוצר קובץ חדש; אף משתמש אחר לא יוצר קובץ ריק בשקט.

### הגדרה חד-פעמית של "בחירת קובץ" (Google Picker)

הכפתור "בחר את קובץ הנתונים המשותף" דורש מפתח API (`PICKER_API_KEY` בראש הקטע "Connecting a NEW user" בשני קובצי ה-HTML):

1. Google Cloud Console ← APIs & Services ← Library ← להפעיל **Google Picker API**.
2. APIs & Services ← Credentials ← Create credentials ← **API key**.
3. להגביל את המפתח: *Application restrictions* = Websites, עם `https://espeton.github.io/*`; *API restrictions* = Google Picker API.
4. להעתיק את המפתח ולהדביק ב-`PICKER_API_KEY` בקובצי `index.html` ו-`tracking/index.html`. (מפתח דפדפן מוגבל לדומיין אינו סוד.)
